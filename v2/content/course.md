## 四個步驟

| 步驟 | 標題 | 說明 |
|---|---|---|
| 〇 | 聽力校準 | 六個人先聽同一段 60 秒、各自獨立標、再比對。十五分鐘。不做這一步，第一步找到的「三位學習者都有的現象」可能只是某一位組員的聽感偏好在三份錄音上重複出現。 |
| 一 | 聽 | 聽三份錄音，逐一標出語音觀察，每一筆都要有音檔編號、時間碼、目標字詞。標完用重現矩陣看哪些現象跨說話人重現。 |
| 二 | 問 | 先自己寫假設，再問 AI，最後比對差異。差異本身就是 AI 協作歷程最好的材料。 |
| 三 | 查 | 用母語×華語音系對照表做對比分析，並帶回至少兩筆 L1 或 L2 層級的來源。 |
| 四 | 教 | 從成立的規律中選一條當教學目標，論證為什麼選它、為什麼不選其他，然後做出糾音方案並試教五分鐘。 |

## 三分類

| 類別 | 名稱 | 說明 |
|---|---|---|
| A | 造成音位混淆 | 聽者會聽成另一個詞。教學目標只能從 A、B 中選。 |
| B | 影響理解但不混淆音位 | 聽者聽得懂，但要花力氣。 |
| C | 僅為口音特徵 | 聽起來不一樣，但不影響理解。報告必須明確列出判為 C 的項目。 |

## 六人角色

| 角色 | 職責 |
|---|---|
| 標註員 A | 獨立標註三份錄音。不看標註員 B 的結果。 |
| 標註員 B | 獨立標註同樣三份錄音，之後與 A 比對。不一致處由全組決議。 |
| 音韻對比 | 負責步驟三的母語×華語音系比較，並帶回至少兩筆 L1 或 L2 來源。 |
| AI 協作紀錄 | 保存所有提問原文與回答，整理成 3–5 則協作紀錄。不負責美化。 |
| 教案設計 | 負責步驟四與 PPT／Canva 教材。必須聽過三份錄音才能動手。 |
| 統整與品管 | 負責一致性檢核、繳交檢核、以及唯一一件事：問「這句話的證據在哪裡」。 |

## 對課程邏輯的建議

| 建議 | 說明 |
|---|---|
| 加一個「步驟〇：聽力校準」 | 六個人先聽同一段 60 秒、各自獨立標、再比對。十五分鐘。這也是學生第一次接觸評分者間信度，成本極低。 |
| 把「規律」寫成操作型定義 | 三位學習者中至少兩位出現，且合計至少三次，才算 tendency。同時要求記錄「該出現而正確的次數」當分母——沒有分母，就沒有辦法談傾向，只能談印象。本工作台已依此計算。 |
| 第二步拆成三小步 | 先假設、再問 AI、最後比對。目前的順序是「聽完直接問 AI 原因」，風險是學生還沒形成自己的判斷就被 AI 的答案錨定。 |
| 把「口音不等於錯誤」變成可操作的判準 | 用 A／B／C 三分類。規定教學目標只能從 A、B 中選，而且報告必須明確列出判為 C 的項目。 |
| 一致性用編號綁死 | 要求教學目標欄位必須填入規律編號（R1、R2…），繳交前做一次自動比對，比口頭提醒有效得多。 |
| 給來源層級 | L1 一手研究、L2 標準參考、L3 教學經驗與二手整理。每條規律至少一項 L1 或 L2，L3 只能當線索。並且明講：查無資料要寫出來，不算失分。 |
| 六人按角色分工，不要按步驟接力 | 按步驟切，前面的人做完就下車，而且教案設計的人從頭到尾沒聽過音檔。設一條硬規定：六個人都要聽完三份錄音。 |
| 講清楚三份產出的讀者不同 | PDF 的讀者是老師與同儕；PPT／Canva 的讀者是那位學習者本人；NotebookLM 的讀者是下一組與未來的自己。建議在作業說明裡各寫一句「它不該是什麼」。 |
| 加五分鐘試教，並只問一個問題 | 組間互換，一方當學習者，五分鐘，結束只問「哪裡你還是不知道要怎麼做」。投入產出比最高的一個環節。 |
| 讓學生的資料回頭檢驗預測 | 標註完成後打開「實證比對」分頁，看自己的觀察跟糾音工作台的預測差在哪裡。**預測落空本身就是發現**，值得寫進報告。 |

## 評分規準

| 項目 | 配分 | 說明 |
|---|---|---|
| 語料標註的可驗證性 | 20% | 每一項觀察都有音檔編號、時間碼、目標字詞；他人可據以回去驗證。校準結果有記錄。 |
| 規律歸納的嚴謹度 | 20% | 有操作型定義；區分規律與個別變異；A／B／C 三分類合理且有依據；有記錄分母。 |
| 音韻比較與查證 | 20% | 母語與華語音系的對比正確；每條規律至少一項 L1 或 L2 來源；查無資料有誠實標示。 |
| AI 協作的專業判斷 | 20% | 3–5 則協作紀錄四欄齊備；看得出學生對 AI 的產出做了查證與修改，而非照單全收。 |
| 分析與教學的一致性 | 20% | 教學目標可回指規律編號；教材內容與分析發現一致；有試教回饋與據以修改的痕跡。 |

## 來源層級

| 層級 | 名稱 | 例子 | 可不可以當唯一依據 |
|---|---|---|---|
| L0 | 語料本身 | 我們自己在音檔裡聽到的，有音檔編號與時間碼可以回去驗證；或用 Praat 等工具量到的數值 | 可以——但只能支持「**我們這批語料裡有這個現象**」，不能推論到「這個母語的學習者都會」 |
| L1 | 一手研究 | 期刊論文、學位論文的實測資料 | 可以 |
| L2 | 標準參考 | 音系描寫、語音學教科書、語料庫技術報告 | 可以 |
| L3 | 教學經驗與二手整理 | 教學網站、部落格、AI 生成的整理 | 不可以，只能當線索 |
