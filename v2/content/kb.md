## 條目

| 標籤 | 診斷 | 操作要領 | 最小對立對 |
|---|---|---|---|
| 送氣／不送氣對立 | 差別不在聲帶振動，而在除阻後那一口氣。母語沒有這個對立時，兩組會聽成同一個音。**先測感知再決定要不要練感知**——西班牙語母語者的感知正確率本來就有八成，瓶頸在產出。 | 紙片測試：手掌或薄紙片放在嘴前三公分，讀 p／t／k 要明顯晃動，讀 b／d／g 幾乎不動。先讓氣流看得見，再進入詞。感知已達標的學習者直接跳到產出練習與錄音回放。 | 爸 bà／怕 pà，搭 dā／他 tā，告 gào／靠 kào |
| 舌尖後 zh/ch/sh | 舌尖翹向硬顎前緣，不是把整個舌頭往後縮。捲舌不足會與舌尖前或舌面音合流。 | 先讓學習者發 sh 的長音並用鏡子確認舌尖位置，穩定後再加成阻變成 zh、ch。一次只練一組對立，不要三組一起上。 | 四 sì／十 shí，造 zào／照 zhào，草 cǎo／炒 chǎo |
| 舌尖前 z/c/s | 舌尖抵住下齒背，摩擦點在齒齦前緣。與舌尖後合流時，「四／十」「造／照」會失去對立。實測顯示 /s/ 與 /ʂ/ 是最容易混的一對，優先處理。 | 用「先發 s 再加塞」的方式建立 z、c；用鏡子與舌位圖確認舌尖沒有翹起。 | 四 sì／十 shí，三 sān／山 shān，早 zǎo／找 zhǎo |
| 舌面 j/q/x | j、q、x 是舌面前音，發音時舌尖要往下放，不是捲起來。用母語的 [ʃ tʃ dʒ] 代替，「西」會聽成「詩」。 | 讓學習者先發 [i] 並保持舌面隆起的位置不動，從那個位置送出擦音就是 x；加上成阻就是 j 與 q。舌尖始終抵住下齒背。 | 西 xī／詩 shī，就 jiù／皺 zhòu，七 qī／吃 chī |
| f 唇齒擦音 | 上齒輕觸下唇，不是雙唇。日語母語者讀成 [ɸ] 多屬口音層次；韓語母語者讀成 [pʰ] 則可能影響辨義，兩者不該同級處理。 | 上齒咬住下唇，先持續發長音 fffff，再接元音。 | 飯 fàn／半 bàn，風 fēng／崩 bēng |
| h 舌根擦音 | 華語的 h 是舌根清擦音，摩擦位置在軟顎，不可省略。省略會讓「好」變成「襖」。 | 從 [k] 的舌位出發但不成阻，形成持續摩擦。手放喉部感受摩擦位置。 | 好 hǎo／襖 ǎo，喝 hē／餓 è，花 huā／挖 wā |
| r 舌尖後濁音 | 舌尖翹起但不接觸、不顫動、不成邊音。屬口音層次，辨義後果小，教學優先序應該低。 | 從 sh 的舌位出發加上聲帶振動即得 r。提醒舌尖「只翹不碰」。 | 熱 rè／樂 lè，肉 ròu／漏 lòu |
| b/d/g 濁化 | 華語的 b、d、g 是不送氣清音，不是濁音，元音間也不擦音化。 | 先確立送氣對立，再處理清濁：讓學習者把手放在喉部，讀 b 時不該感到明顯振動起始。 | 大 dà／他 tā，布 bù／舖 pù |
| n/l 混淆 | 差別在氣流從鼻腔還是舌側出去。捏鼻測試最直接。 | 捏住鼻子讀 n，聲音會悶住甚至發不出來；讀 l 則不受影響。 | 你 nǐ／李 lǐ，男 nán／藍 lán |
| 單韻母 e [ɤ] | 後半高不圓唇元音，不是 [ə]、[ɛ] 或 [e]。 | 從 o 的舌位出發，把嘴唇放平不圓即得 e。 | 餓 è／愛 ài，樂 lè／拉 lā，得 dé／大 dà |
| 撮口呼 ü [y] | 舌位與 i 相同，唇形與 u 相同。換成 [u]、[ju] 會造成辨義失誤。 | 先發 i 並保持舌位不動，只把嘴唇圓起來，舌頭不可後縮。 | 魚 yú／無 wú，女 nǚ／努 nǔ，居 jū／租 zū |
| 鼻韻尾 -n／-ng | -n 是舌尖抵上齒齦，-ng 是舌根抵軟顎。合流會讓「因／英」「班／幫」失去對立。**大規模語料顯示逾六成是 -ng 讀成 -n**，先查方向再決定怎麼教。 | 延長韻尾讓差異可感：讀 an 時舌尖必須貼住並停住兩秒，讀 ang 時舌尖離開、舌根上抬。先做聽辨，正確率八成再進產出。 | 因 yīn／英 yīng，班 bān／幫 bāng，新 xīn／星 xīng |
| 元音鼻化 | 華語的鼻韻母是「元音＋鼻輔音韻尾」，元音本身不鼻化。 | 分兩段練：先讀乾淨的口元音，再加韻尾，中間可先刻意斷開再逐步縮短。捏鼻測試：讀元音段時捏住鼻子音色不該改變。 | 安 ān／骯 āng，天 tiān／聽 tīng |
| 複韻母滑移不足 | 複韻母有明確的滑移方向與長短分配，單元音化會讓音節像被截斷。 | 用手勢畫滑移方向並拉長練習，再逐步壓縮到正常時長。 | 說 shuō／濕 shī，走 zǒu／早 zǎo |
| er 與兒化 | 兒化不是加一個音節，而是把捲舌動作疊到韻母上。 | 先讓學習者讀單獨的 er，再把同一個舌位疊到前一個韻母的尾巴。 | 一點 yìdiǎn／一點兒 yìdiǎnr |
| 韻母央化 | 非重讀位置的韻母被讀成 [ə]，是母語弱化習慣的移入。 | 先用單念確認學習者讀得出正確韻母，再放回詞裡慢速練習。 | 得 dé／的 de |
| 一聲 調域偏低 | 陰平要落在調域高處並保持平穩，偏低會與其他聲調的空間擠在一起。 | 先建立學習者自己的調域上下限，把五度標在這個區間上，再定位陰平的絕對高度。 | 媽 mā／麻 má，書 shū／熟 shú |
| 二聲 上升不足 | 陽平是從中音區一路上升到高音區。上升幅度不足會與陰平或三聲相混。實測顯示二聲是最難辨識的一個聲調。 | 手勢斜向上，並要求終點明顯高於起點。可先誇張化再收回。 | 買 mǎi／埋 mái，五 wǔ／無 wú |
| 三聲 只降不升 | 完整上聲是 214：降到調域最低點再上升。只降不升會聽起來像去聲。 | 手勢打勾，在低點刻意停一拍再上升。提醒完整 214 只在單念或句末出現。 | 馬 mǎ／罵 mà，五 wǔ／霧 wù |
| 四聲 降幅不足 | 去聲從調域最高點直落到最低點。降幅不足會與陰平相混。注意：一／四聲這一對在訓練研究中最抗拒改善。 | 從高處起音是關鍵：先拉高再放掉，配合手臂由上往下揮。 | 書 shū／樹 shù，西 xī／細 xì |
| 二聲／三聲對立 | 差別在「有沒有先降下去」與「起點高低」，不在最後是不是升。這是最常造成辨義失誤的一項，也是唯一有直接訓練實證的一項。 | 先做感知：教師念單字，學習者只回答「有沒有先掉下去」。再用手勢畫調型。單字穩定後立刻進入雙音節，因為上聲在連讀中多半只讀半三聲。高變異度訓練（多位說話人、多個詞）可遷移到新詞與新說話人。 | 買 mǎi／埋 mái，好 hǎo／豪 háo，李 lǐ／離 lí |
| 四聲整體調域壓縮 | 問題不在調型方向，而在四個聲調全部擠在很窄的音高範圍內，彼此距離不夠。 | 先讓學習者唱出自己最舒服的最高音與最低音，把五度標在這個區間上，再逐一定位四聲的起訖點。 | 媽／麻／馬／罵，湯／糖／躺／燙 |
| 三聲連讀變調 | 這是規則問題，不是發音問題。要先分清楚學習者是「不知道規則」「知道但來不及執行」還是「規則用過頭」。第三種在中級學習者身上很常見。 | 不知道規則：板書寫成公式，用固定詞組重複到自動化。來不及執行：降低語速練習，別再重講規則。用過頭：給對比組，讓學習者自己找界線。 | 你好、很好、水果、雨傘、老鼠 |
| 「一」的變調 | 「一」在去聲前讀陽平、在其他聲調前讀去聲、單念與序數讀陰平。屬規則家族，應與三聲變調一起教。 | 用同一張規則表把「一」「不」「三聲」放在一起，讓學習者看見它們是同一類問題。 | 一個／一天／一年／第一 |
| 「不」的變調 | 「不」只在去聲前讀陽平，其餘讀去聲。 | 同上，與「一」合併教學。 | 不對／不好／不來／不忙 |
| 半三聲 | 上聲在非句末位置多半只讀 21，不上升。學習者若執著於完整 214，語流會顯得不自然。 | 明確告訴學習者「完整的三聲其實很少出現」，再用雙音節詞大量練習。 | 老師、水果、美國、請問 |
| 規則過度泛化 | 學習者把規則套用到不該套用的地方，這是習得進展的訊號，不是退步。追蹤研究顯示：韓語母語者的三聲反而隨學習時間拉長而越來越像二聲，正是規則蓋過聲學直覺。 | 不要重講規則，改為給對比組：可以變的與不可以變的放在一起，讓學習者自己找出界線。 | 很好（變）／老師（不變） |
| 輕聲時長未縮短 | 輕聲牽涉音高、時長、音強三個參數。時長最容易感知也最容易控制，從它入手。母語缺乏系統性元音弱化機制的學習者（法語、西班牙語）這一項最難。 | 用拍手打節奏，輕聲音節只給半拍。時長穩定後再處理音高。 | 東西 dōngxi／東西 dōngxī，孫子 sūnzi |
| 輕聲音高 | 輕聲的音高依前一個字的聲調決定，不是固定的低調。 | 先固定練同一個前字聲調的詞組，穩定後再換前字聲調，讓學習者自己發現音高跟著變。 | 媽媽、爺爺、姐姐、弟弟 |
| 輕聲讀為本調 | 保留本調並加重，是母語重音格局的直接移入。 | 先讓學習者聽兩個版本的對比，確認他聽得出差別，再進入產出。 | 東西、意思、朋友、休息 |
| 辨義輕聲 | 少數詞的輕聲與否會改變詞義，這一類最值得教，因為動機最明顯。 | 用辨義對比建立動機，再擴展到一般輕聲詞。 | 東西 dōngxi／東西 dōngxī，大意 dàyi／大意 dàyì |
| 句調覆蓋字調 | 字調單念時正確，一進入句子就被母語的語調曲線吃掉。這一項需要較長週期。注意：單字調的觀察不能直接推論到語流層次。 | 先慢後快：把句子拆成單字念準，再以極慢速連讀並保持每個字的調型，然後逐步加速，全程錄音對照。 | 他來了。／他來了？ |
| 節奏型（弱化不足） | 母語缺乏系統性非重讀元音弱化的學習者，華語的輕重長短分配會消失。這通常歸為 B 類：不混淆音位，但聽者要費力。 | 用拍子教：重讀音節一拍、輕聲半拍。先用兩字詞，再擴到四字短語。 | 老師好、謝謝你、不客氣 |
| 停頓位置 | 停在詞的中間或該停的地方不停，會讓聽者需要重新分析句子結構。 | 用斜線標出意群，先照著念，再逐步拿掉標記。 | 我／昨天／在圖書館／看書 |
| 語速與流暢度 | 語速本身不是問題，該關注的是停頓與修補是否讓聽者跟不上。 | 不要要求說快，要求的是「停在對的地方」。 | |
| 詞重音位置 | 把母語的詞重音規則移到華語詞上，多半屬 B 類。 | 用雙音節詞的輕重對比練習，並與輕聲教學合併。 | 東西、學生、朋友 |
| 預設 | 這個現象的核心是目標音的特徵與學習者母語的對應音不一致，需先建立感知上的區辨，再進入產出。 | 以最小對立對建立聽辨，再用鏡子與發音部位圖定位，最後從單音節逐步擴展到語流。 | |
